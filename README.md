# RsnChat Bot

Bot created to use rsnchat AI and xhub-ai, with various features to facilitate your use of the API and other resources.


## Features

- Using rsnchat AI to generate images and have conversations with the bot
- Also using xhub-ai to get +18 images 
- System with MongoDB

## How to use the Bot?

Clone the project

```bash
  git clone https://github.com/rsnlabs/rsnlabs-free-bot.git
```

Enter the project directory

```bash
  cd rsnlabs-free-bot
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run start
```
